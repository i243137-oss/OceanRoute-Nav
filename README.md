
# OceanRoute Nav



![OceanRoute Nav](./demo.gif)



OceanRoute Nav is a polished, interactive toolkit for plotting and exploring ocean routes. This README was updated to provide a friendly quick-start, examples, and contribution guidance.



---



## Quick Highlights



- Fast route visualization and smoothing algorithms

- Small, dependency-friendly C++ core with examples

- Clear build instructions and demos included in `examples/`



---



## Quick Start



1. Clone:



   git clone https://github.com/i243137-oss/OceanRoute-Nav.git

   cd OceanRoute-Nav


2. Build (CMake):


   mkdir build && cd build

   cmake ..

   cmake --build . --config Release


3. Run an example from `build\bin`.
